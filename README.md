# Vortix Kitchen — Induction & Infrared Cooker Manufacturer (OEM/ODM)

**Vortix Kitchen** (Foshan Vortix Co., LTD) is an OEM/ODM manufacturer of induction cookers, infrared cookers, and dual-zone cooktops for importers and distributors across Central Asia, Southeast Asia, and Africa.

🌐 **Official website:** https://vortixkitchen.com

This repository hosts the source of the official B2B inquiry site. It publishes free buyer guides that help importers avoid the costly traps of sourcing cookers from China — customs holds, voltage/frequency mismatch, dead-on-arrival units from under-specced IGBTs, and unsafe 100% upfront payment.

## Product lines
- **Induction cookers** — D / A / B / SY / ST / T series
- **Infrared cookers** — C series (works with any pot)
- **Dual-zone cooktops** — DCL series
